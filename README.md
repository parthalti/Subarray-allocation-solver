# Subarray Allocation Solver

A Python notebook exercise for finding subarrays whose sums satisfy a constraint, with example test cases and printed results.

## What it demonstrates

- Processing multiple test cases
- Evaluating candidate subarrays against a sum constraint
- Reporting a best feasible subarray when one is found
- Handling cases where no feasible subarray is found

## Run

Open `Practical4.ipynb` in Jupyter Notebook or Google Colab and run the cells.

[Open the notebook](https://github.com/parthalti/Subarray-allocation-solver/blob/main/Practical4.ipynb)

The notebook is the source of truth for the exact input format and constraint details.
